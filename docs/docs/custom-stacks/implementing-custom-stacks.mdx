# Implementing Custom Stacks

You can create your own custom stacks with TypeScript by implementing <ApiLink text="CustomStackHandler" source="interfaces/CustomStackHandler.html"/> interface.
Let’s walk through how this works in practice by implementing a custom stack handler that we use to deploy CloudFormation stacks 😀.

## Custom Stack State

First, you need to decide what information you want to expose in your custom stack's state.
The only requirement is that the state object must implement <ApiLink text="CustomStackState" source="types/CustomStackState.html"/> interface.

Create `my-custom-stack.ts` file and place it in the `src` directory of your Takomo project.
Add the following content into the file.

```typescript title=src/my-custom-stack.ts {1-5}
import { CustomStackState } from 'takomo';

type MyCustomStackState = CustomStackState & {
  // Here we can add more state information later
};
```

## Custom Stack Configuration

Next, you need to decide what information you want to pass for your custom stack handler from stack configuration files.
As we are building a handler for CloudFormation, we propably want to be able to pass stack template.

```typescript title=src/my-custom-stack.ts {7-9}
import { CustomStackState } from 'takomo';

type MyCustomStackState = CustomStackState & {
  // Here we can add more state information later
};

type MyCustomStackConfig = {
  stackTemplate: string;
};
```

## Custom Stack Type

Each custom stack handler needs to have a unique type which you can reference from stack configuration files.

```typescript title=src/my-custom-stack.ts {1,11-16}
import { CustomStackState, CustomStackHandler } from 'takomo';

type MyCustomStackState = CustomStackState & {
  // Here we can add more state information later
};

type MyCustomStackConfig = {
  stackTemplate: string;
};

export const myCustomStackHandler: CustomStackHandler<
  MyCustomStackConfig,
  MyCustomStackState
> = {
  type: 'my-custom-stack',
};
```

## Parsing Custom Stack Configuration

It's the responsibility of a custom stack handler to parse and validate its own configuration the user specifies in stack configuration files.
Implement `parseConfig` function.

```typescript title=src/my-custom-stack.ts {4-5,21-46}
import {
  CustomStackState,
  CustomStackHandler,
  ParseConfigProps,
  ParseConfigResult,
} from 'takomo';

type MyCustomStackState = CustomStackState & {
  // Here we can add more state information later
};

type MyCustomStackConfig = {
  stackTemplate: string;
};

export const myCustomStackHandler: CustomStackHandler<
  MyCustomStackConfig,
  MyCustomStackState
> = {
  type: 'my-custom-stack',
  parseConfig: async ({
    rawConfig,
  }: ParseConfigProps): Promise<ParseConfigResult<MyCustomStackConfig>> => {
    const configObj = rawConfig as Record<string, unknown>;

    // Validate that stackTemplate property is defined
    if (configObj.stackTemplate === undefined) {
      return {
        success: false,
        message: 'stackTemplate is required in custom stack config',
      };
    }

    // Validate that stackTemplate is of type string
    if (typeof configObj.stackTemplate !== 'string') {
      return {
        success: false,
        message: 'stackTemplate is must be string in custom stack config',
      };
    }

    return {
      success: true,
      parsedConfig: configObj as MyCustomStackConfig,
    };
  },
};
```

const arrayToRecord = <T extends object, K extends string | number | symbol, V>(
  array: ReadonlyArray<T>,
  keyExtractor: (item: T) => K,
  valueExtractor: (item: T) => V,
): Record<K, V> =>
  array.reduce(
    (collected, item) => ({
      ...collected,
      [keyExtractor(item)]: valueExtractor(item),
    }),
    {} as Record<K, V>,
  );

// Utility function to convert a CloudFormation stack to a CustomStackState
const convertToCustomStackState = (stack?: Stack): CustomStackState => {
  if (!stack) {
    return { status: 'PENDING' };
  }

  const outputs = arrayToRecord(
    stack.Outputs ?? [],
    (output) => output.OutputKey!,
    (output) => output.OutputValue!,
  );

  const tags = arrayToRecord(
    stack.Tags ?? [],
    (tag) => tag.Key!,
    (tag) => tag.Value!,
  );

  const parameters = arrayToRecord(
    stack.Parameters ?? [],
    (param) => param.ParameterKey!,
    (param) => param.ParameterValue!,
  );

  return { status: 'CREATE_COMPLETE', outputs, tags, parameters };
};

// Utility function to describe a CloudFormation stack
const describeStack = async (
  client: CloudFormationClient,
  stackName: string,
): Promise<CustomStackState | undefined> => {
  try {
    const { Stacks = [] } = await client.send(
      new DescribeStacksCommand({ StackName: stackName }),
    );

    if (Stacks.length === 0) {
      return undefined;
    }

    return convertToCustomStackState(Stacks[0]);
  } catch (e) {
    const error = e as any;
    if (error.Code === 'ValidationError') {
      if (error.message === `Stack with id ${stackName} does not exist`) {
        return undefined;
      }
    }

    throw e;
  }
};

## Register Custom Stack Handler

To actually use our custom stack handler, we need to register it in `takomo.ts` file located in your project's root directory.

```typescript
import { TakomoConfig, TakomoConfigProvider } from 'takomo';
import { myCustomStackHandler } from './src/my-custom-stack.js';

const provider: TakomoConfigProvider = async (): Promise<TakomoConfig> => {
  return {
    customStackHandlers: [myCustomStackHandler],
  };
};

export default provider;
```

## Using Custom Stack Handler in Stack Configuration

Now that we have implemented our custom stack handler and registered it in Takomo project configuration, we can start using it in stack configuration files.
Add a stack configuration file named `my-stack.yml` to the `stacks` directory. Set `customType` to `my-custom-stack` and provide template for your stack with `customConfig` property.

```yaml
regions: eu-north-1
customType: my-custom-stack
customConfig:
  stackTemplate: |
    Resources:
      LogGroup:
        Type: AWS::Logs::LogGroup
        Properties: {}
tags:
  Project: My example stack
```

# From Takomo 9.x to 10.x

Takomo 10.0 is a maintenance release with only one breaking change. Upgrading from 9.x should be straightforward.

## Breaking changes

Here is the breaking change introduced in Takomo 10.0.

- [Require Nodejs 24.14.0](#require-nodejs-24140)

### Require Nodejs 24.14.0

Nodejs 24.14.0 is now required to run Takomo. This change makes it possible to keep upgrading project dependencies to their latest versions in the future.

**Required actions**

Upgrade your Nodejs to version 24.14.0 or later.

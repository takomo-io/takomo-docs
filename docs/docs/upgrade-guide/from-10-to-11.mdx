# From Takomo 10.x to 11.x

Takomo 11.0 is a maintenance release with only one breaking change. Upgrading from 10.x should be straightforward.

## Breaking changes

Here is the breaking change introduced in Takomo 11.0.

- [Require Nodejs 26.5.1](#require-nodejs-2651)

### Require Nodejs 26.5.1

Nodejs 26.5.1 is now required to run Takomo. This change makes it possible to keep upgrading project dependencies to their latest versions in the future.

**Required actions**

Upgrade your Nodejs to version 26.5.1 or later.

# Takomo 9.0 released

We are happy to announce Takomo 9.0.0 release!

Takomo 9.0 adds support for [custom stacks](../docs/custom-stacks/introduction.mdx) and introduces one breaking change. Upgrading from 8.x should be straightforward.

**Breaking changes**

- Changes to exposed Takomo APIs

See [upgrade guide](../docs/upgrade-guide/from-8-to-9) to learn required actions when upgrading from Takomo 8.x to 9.x.

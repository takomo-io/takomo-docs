# Takomo 11.0 released

We are happy to announce Takomo 11.0.0 release!

This is a maintenance release that introduces only one breaking change.

**Breaking changes**

- [Require Nodejs 26.5.1](../docs/upgrade-guide/from-10-to-11#require-nodejs-2651)

See [upgrade guide](../docs/upgrade-guide/from-10-to-11) to learn required actions when upgrading from Takomo 10.x to 11.x.

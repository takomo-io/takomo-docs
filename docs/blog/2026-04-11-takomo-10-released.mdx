# Takomo 10.0 released

We are happy to announce Takomo 10.0.0 release!

This is a maintenance release that introduces only one breaking change.

**Breaking changes**

- [Require Nodejs 24.14.0](../docs/upgrade-guide/from-9-to-10#require-nodejs-24140)

See [upgrade guide](../docs/upgrade-guide/from-9-to-10) to learn required actions when upgrading from Takomo 9.x to 10.x.
